# Linux Security Audit

## Overview

This project documents a basic security assessment of a Kali Linux system performed in a controlled lab environment.

The goal was to seek exposed network services, review running services, examine firewall configuration, and then document potential security risks.

## Objective

The objectives of this is were to:

- Identify listening network ports
- Identify running services
- Review firewall configuration
- Determine which services may be unnecessarily exposed
- Document security findings

## Environment

- Operating System: Kali Linux
- Environment: Virtual Machine / Controlled Lab
- Tools: Linux CLI, ss, systemctl, UFW/nftables
