# Cybersecurity Portfolio

Welcome to my cybersecurity repo. This is where I keep my labs and projects I've worked on in a Linux environment

I use this repo to keep track of my work I've  done, the tools I used, and the results I got from each lab.

## Projects

### Network Scan Investigation

**Folder:** `network-scan-investigation`

**Tools:** Nmap, Kali Linux, Linux networking tools

I used Nmap to scan systems in my lab and find open ports, identify running services, and look into anything that stood out. 

### Vulnerability Assessment Lab

**Folder:** `vulnerability-assessment-lab`

**Tools:** Nmap, Kali Linux, Linux security tools

I used network scanning and security checks to look for exposed services and  weaknesses. I then documented the results to look at what could be done to reduce the risk.

### Firewall Defense Lab

**Folder:** `firewall-defense-lab`

**Tools:** Linux firewall tools, Kali Linux

I worked with firewall rules to control network traffic. I tested each rules before and after making changes to see what traffic was allowed or blocked and documented those results.

### Linux Security Audit

**Folder:** `linux-secuirty-audit`

**Tools:** Kali Linux, `ss`, `systemctl`, SSH, `journalctl`, `grep`

I audited a Linux system by checking running services, listening ports, and system configuration. 

### SSH Brute-Force Investigation

**Folder:** `ssh-bruteforce-investigation`

**Tools:** SSH, journalctl, grep, Linux authentication logs

I created controlled failed SSH login attempts against my own lab system and then searched the resulting logs. 

### Python Security Log Analyzer

**Folder:** `Python-Security-Log-Analyzer`

**Tools:** Python 3, Regex, Linux security logs

I wrote Python scripts to make security log analysis easier. The scripts look for failed login attempts and pull out IP addresses, count repeated failures, and flag IPs that pass the threshold.
