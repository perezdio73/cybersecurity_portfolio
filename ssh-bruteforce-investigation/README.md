# SSH Brute-Force Investigation Lab

## Overview

This project demonstrates the investigation of repeated
failed SSH authentication attempts against a Linux system.

The investigation was performed in a controlled Kali Linux
lab environment.

## Objective
Seek and analyze repeated SSH authentication failures,
determine the source of the activity, then automate log analysis
and document the incident.

## Tools

- Kali Linux
- OpenSSH
- Linux journal logs
- Python 3
- Regular expressions
- Wireshark/Network analysis concepts

## Investigation Process

1. Generated controlled failed SSH authentication attempts.
2. Collected SSH authentication logs.
3. Identified failed login events.
4. Analyzed source IP addresses.
5. Automated analysis using Python.
6. Identified repeated authentication activity.
7. Documented the incident timeline.
8. Mapped the behavior to MITRE ATT&CK.

## Files

### failed_logins.txt
Authentication events collected from the Linux system.

### failed_login_analysis.py
Python script that extracts and counts source IP addresses
from failed authentication events.

### analysis_results.txt
Output generated by the Python analysis script.

### incident_report.md
Security investigation report.

### timeline.md
Timeline of observed activity.

### mitre_mapping.md
MITRE ATT&CK technique mapping.
