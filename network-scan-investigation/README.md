# Network Scan Detection & Investigation

## Overview

This project shows the detection and search of a
controlled network activity.

An Nmap TCP SYN scan was performed against a Kali Linux system
in a controlled lab environment. Wireshark was then used to
analyze the network traffic.

## Objective

- Generated search locating traffic
- Capture the traffic using Wireshark
- Identify the scanning behavior
- Determine the source and destination
- Analyze targeted ports
- Document security implications

## Tools

- Kali Linux
- Nmap
- Wireshark
- TCP/IP

## Investigation Workflow

Nmap Scan
↓
Packet Capture
↓
Wireshark Analysis
↓
Identify SYN Traffic
↓
Analyze Ports
↓
Document Findings
